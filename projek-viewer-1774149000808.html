📚 Dokumentasi Format JSON

📋 Struktur Header

{
  "title": "Nama Paket Soal",
  "time": 60,
  "token": "TOKEN123",
  "icon": "📐",
  "color": "blue",
  "questions": [...]
}

time: waktu dalam menit. token: password paket. color: blue/green/purple/red/yellow.

📝 Tipe: Pilihan Ganda (MC)

{
  "type": "MC",
  "category": "Aljabar",
  "text": "Berapakah $\\frac{-b \\pm \\sqrt{D}}{2a}$ jika...",
  "image": "https://...(opsional)",
  "options": ["Opsi A","Opsi B","Opsi C","Opsi D","Opsi E"],
  "answer": 0,
  "explanation": "Penjelasan jawaban."
}

answer: index opsi (0=A, 1=B, dst). Gunakan $...$ untuk LaTeX inline.

☑️ Tipe: Pilihan Ganda Kompleks (CMC)

{
  "type": "CMC",
  "category": "Geometri",
  "text": "Pilih semua yang benar...",
  "options": ["Opsi 1","Opsi 2","Opsi 3","Opsi 4"],
  "answer": [0, 2],
  "explanation": "Opsi 1 dan 3 benar karena..."
}

answer: array index yang benar (min. 2).

✅❌ Tipe: True/False (TF)

{
  "type": "TF",
  "category": "Logika",
  "text": "Tentukan benar/salah:",
  "statements": [
    {"text": "Pernyataan 1", "answer": true},
    {"text": "Pernyataan 2", "answer": false}
  ],
  "explanation": "Penjelasan..."
}

Skor TF: benar semua=1, sebagian=0.5, salah semua=0.

🧮 Penulisan LaTeX

Inline: $x^2 + y^2 = r^2$

Display: $$\\int_0^1 x^2 dx = \\frac{1}{3}$$

Fraksi: $\\frac{a}{b}$ | Akar: $\\sqrt{x}$ | Pangkat: $x^{n}$
